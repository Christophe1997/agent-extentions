# ascii2img

Render ASCII-art diagrams to PNG images. Auto-activates when you paste a box/line diagram or when Claude produces one — the skill checks dependencies, converts via `svgbob` + `rsvg-convert`, and returns the image path.

## Features

### Skills

| Skill | Trigger | Description |
|-------|---------|-------------|
| `ascii2img` | Auto | Detects ASCII-art diagrams in conversation or files and renders them to PNG |

## Examples

Paste a diagram directly — the skill activates and produces `./<slug>.png` in the current working directory:

```
        +-----------+      +-----------+
        |   Client  +----->|   Server  |
        +-----------+      +-----------+
```

Or point at an existing `.bob` file:

```
Render plugins/ascii2img/examples/architecture.bob
```

The PNG is written next to the source (e.g., `architecture.png`).

## Installation

**Requirements:**

- [`svgbob`](https://github.com/ivanceras/svgbob) — ASCII → SVG renderer
- [`librsvg`](https://wiki.gnome.org/Projects/LibRsvg) (`rsvg-convert`) — SVG → PNG converter; ImageMagick (`magick`/`convert`) is used as a fallback if `rsvg-convert` is unavailable

```bash
# macOS
brew install svgbob librsvg

# Linux (Debian/Ubuntu)
cargo install svgbob_cli
sudo apt-get install librsvg2-bin
```

```bash
/plugin install ascii2img@agent-extentions
```

If any dependency is missing, the skill will surface the correct install command and offer to run it.

## Usage

### Auto-rendering

The skill activates whenever Claude sees an ASCII-art diagram — either pasted by you or generated by Claude itself. No command needed.

### Explicit rendering

Ask Claude to "render this as a PNG" or "convert this ASCII diagram to an image" and it will invoke the script directly.

### Custom output and zoom

Invoke the script manually if you want control over output path or resolution:

```bash
bash plugins/ascii2img/skills/ascii2img/scripts/render.sh input.bob output.png 3
```

- `output.png` (optional) — defaults to `<input>.png` next to the source file
- `zoom` (optional) — defaults to `2`; passed to `rsvg-convert -z`
