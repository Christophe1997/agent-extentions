# Review Blog

Review Chinese blog posts for writing style, punctuation, and formatting issues. Based on [ruanyf/document-style-guide](https://github.com/ruanyf/document-style-guide).

## Features

### Skills

| Skill | Description |
|-------|-------------|
| `review-blog` | Review a blog post for style issues and offer to apply fixes |

## Installation

```bash
/plugin install review-blog@agent-extentions
```

## Usage

```bash
/review-blog content/posts/my-post.md
```
